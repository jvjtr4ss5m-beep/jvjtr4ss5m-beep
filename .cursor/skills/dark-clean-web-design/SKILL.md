# Dark Clean Web Design

## 목표
- 다크 테마 기반의 깔끔하고 신뢰감 있는 웹 UI를 만든다.
- 불필요한 장식 없이 타이포그래피, 여백, 정보 위계로 완성도를 만든다.
- `adri-fluid-demo.squarespace.com`의 분위기(차분한 포트폴리오/에이전시 톤)를 참고하되 그대로 복제하지 않는다.

## 적용 트리거
- 사용자가 다크 테마, 미니멀, 세련된 랜딩 페이지/포트폴리오 스타일을 요청할 때
- 기존 UI를 더 정돈된 다크 스타일로 개선해달라고 할 때
- “깔끔한 웹 디자인”, “modern dark”, “portfolio vibe”, “agency vibe” 성격의 요청일 때

## 디자인 규칙
1. 색상
   - 기본 배경: 거의 검정(`rgb(10~20, 10~20, 10~20)`)
   - 기본 텍스트: 저채도 오프화이트(`rgb(235~245, 235~245, 235~245)`)
   - 보조 텍스트: 중간 명도 회색
   - 강조색: 1개만 사용(저채도 블루/퍼플/그린 중 택1), 과도한 그라데이션 금지

2. 타이포그래피
   - 헤드라인은 명확하고 짧게, 본문은 2~3문장 단위로 끊는다.
   - 제목/본문 크기 대비를 분명히 둔다.
   - 한 화면에 서로 다른 폰트 역할은 최대 2개로 제한한다.

3. 레이아웃
   - 섹션 단위로 넉넉한 세로 여백을 둔다.
   - 한 줄 길이를 과도하게 늘리지 않는다(읽기 폭 제한).
   - 카드/블록 사용 시 모서리, 테두리, 그림자를 약하게 유지한다.

4. 컴포넌트 톤
   - 버튼은 단순한 형태(채움 또는 아웃라인 중 하나)를 유지한다.
   - 애니메이션은 짧고 절제되게(hover/fade/slide 소량).
   - 아이콘/배지/장식 요소는 의미가 있을 때만 추가한다.

5. 콘텐츠 구조
   - Hero: 한 줄 가치 제안 + 짧은 보조 설명 + 명확한 CTA
   - 신뢰 섹션: 숫자/성과/고객 코멘트 등 증거를 간결하게 배치
   - 사례/서비스 섹션: 카드나 리스트로 스캔 가능하게 구성

## 구현 절차
1. 페이지 목적(전환, 소개, 포트폴리오)을 먼저 정의한다.
2. 3단 위계(Hero → 핵심 정보 → 보조 정보)로 섹션을 재배열한다.
3. 다크 테마 색상 토큰을 먼저 정하고 이후 컴포넌트에 일괄 적용한다.
4. 타이포 스케일과 간격 스케일을 먼저 고정한 뒤 세부 스타일을 맞춘다.
5. 마지막에 강조색 사용 빈도를 줄여 시선 집중 포인트만 남긴다.

## 출력 기준
- 결과물은 “첫 화면 3초 내 핵심 메시지 인지”가 가능해야 한다.
- 동일 페이지 내 시각 규칙(색상/간격/모서리/버튼 스타일)이 일관되어야 한다.
- 과한 효과보다 정보 전달 우선으로 마감한다.

## 금지 사항
- 네온 컬러 다중 사용
- 과도한 그림자, 블러, 패럴랙스
- 섹션마다 다른 디자인 언어 사용
- 텍스트 대비가 낮아 가독성이 떨어지는 조합
